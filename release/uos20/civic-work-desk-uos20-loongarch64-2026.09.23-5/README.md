# 政务工作记录台 — 安装与使用（UOS 工作站）

本包是**用户级**安装包：全部装在你自己的目录下，**不需要管理员密码**，不安装任何系统服务，
不需要联网。

---

## 一、安装

把安装包复制到工作站，然后：

```sh
sha256sum -c civic-work-desk-uos20-loongarch64-<版本>.tar.gz.sha256
tar -xzf civic-work-desk-uos20-loongarch64-<版本>.tar.gz
cd civic-work-desk-uos20-loongarch64-<版本>
sh install.sh
```

第一条命令必须显示 `OK`。显示别的内容说明文件在传输中损坏了，**不要继续安装**，重新取一份。

安装程序会校验包内每个文件、把新版本先复制到暂存目录并再校验一遍、然后切换到新版本、装菜单项，
最后启动本地服务并自检一次。

失败时它是这样处理的（**不是**「全有或全无」，请照实理解）：

- **校验或复制阶段失败** —— 正在使用的版本和正在运行的服务完全不动，等于什么都没发生；
- **切换版本这一步** —— 很短，切换完会读回核对；没切成功就还是原来的版本；
- **切换之后的步骤失败**（装菜单项、启动服务）—— 新版本**已经装好并启用了**，只是集成或启动这一步
  没成。它会明确报错并告诉你怎么办；**重新运行同一个安装包就会把它补上**；
- 任何一种失败都会明确报错，**不会把失败说成成功**。

## 二、使用

从开始菜单打开「**政务工作记录台**」。

第一次打开会启动一个只监听本机的小型文件服务，然后在默认浏览器里打开：

```
http://127.0.0.1:8765/
```

用完直接关浏览器即可。本地服务留着不影响任何东西，下次打开更快。
**重复点击菜单项是安全的**——不会启动第二个服务。

## 三、这个地址非常重要

浏览器按「来源」隔离本地数据，来源由 **协议 + 主机 + 端口** 三项共同决定。三项里任何一项不同，
就是另一个存储空间：

| 地址                     | 结果                       |
| ------------------------ | -------------------------- |
| `http://127.0.0.1:8765/` | 你的数据在这里             |
| `http://localhost:8765/` | 另一个来源，里面是**空的** |
| `http://127.0.0.1:8080/` | 另一个来源，里面是**空的** |
| 换浏览器 / 换浏览器配置  | 里面是**空的**             |

所以：**不要自己改端口，也不要用 localhost 打开。**
如果哪天打开发现「数据没了」，第一件事是**看地址栏**，而不是找备份。

端口 8765 被占用时，启动器会明确报错并停止，**不会**自动换一个端口——换端口会打开一个空数据库，
看起来和数据丢失一模一样。

## 四、数据在哪里，备份是什么

| 东西     | 位置                              | 删掉会怎样               |
| -------- | --------------------------------- | ------------------------ |
| 程序文件 | `~/.local/share/civic-work-desk/` | 程序打不开，**数据还在** |
| 业务数据 | **浏览器**里（IndexedDB）         | **数据没了**             |
| 备份文件 | 你的下载目录（应用导出的 JSON）   | 失去唯一可移植的恢复手段 |

**复制或删除程序目录，既不会备份也不会删除你的数据。**
唯一可移植的备份是应用里「设置 → 数据与备份 → 导出 JSON 备份」生成的那个文件。

下面每一件事之前，**先导出一份 JSON 备份**：

- 升级或回退本程序；
- 重装、重置或更换 360 浏览器；
- 清理浏览器站点数据；
- 系统维护、重装、换机。

## 五、命令

安装后有五个命令。从菜单启动不需要用到它们；出问题时第一个最有用。

| 命令                        | 作用                                   |
| --------------------------- | -------------------------------------- |
| `civic-work-desk-status`    | 看当前状态（**出问题先跑这个**）       |
| `civic-work-desk`           | 启动并打开浏览器（菜单项调用的就是它） |
| `civic-work-desk-stop`      | 停止本地服务                           |
| `civic-work-desk-rollback`  | 回退到上一个程序版本                   |
| `civic-work-desk-uninstall` | 卸载程序（**不会**删除浏览器里的数据） |

如果终端里提示「找不到命令」，说明 `~/.local/bin` 不在 PATH 里。菜单项不受影响；
要在终端里用，把这一行加进 `~/.bashrc`：

```sh
export PATH="$HOME/.local/bin:$PATH"
```

## 六、升级

装新版本就是再跑一次新包里的 `install.sh`。它会：

1. 校验新包；
2. 保留当前版本作为「上一版本」；
3. 切换到新版本并重启本地服务；
4. 自检新版本。

升级**不动**浏览器里的数据，**不动**浏览器配置，**不清除**缓存。

如果升级时浏览器还开着旧页面，页面顶部会出现「有新版本可用」，点「应用更新」即可；
也可以关掉标签页从菜单重新打开。**不需要清除浏览器数据**——那会连带影响你的记录。

## 六之二、修复（菜单项没了、命令没了、装到一半）

**重新运行同一个安装包就行。**

```sh
cd civic-work-desk-uos20-loongarch64-<版本>
sh install.sh
```

同一个版本再装一次**不是**空操作。安装程序会：

1. 先核对已安装的程序文件与安装包是否一致；
2. 一致 —— 只把**部署集成**补回来：运行库、五个命令、菜单项、必要的目录。
   **不会**重新复制或删除程序文件，**不会**动浏览器里的数据，**不会**改地址；
3. 最后核对一遍：运行库、五个命令、菜单项、版本指针都在，才算成功。

适用于：菜单里找不到图标了 · 终端里找不到命令了 · 上次安装中途失败了 · 不确定装没装全。

### 如果核对发现程序文件与安装包不一致

安装程序会**明确拒绝**，并且**不会**就地覆盖正在使用的版本目录——那需要先删掉它，
中途失败就没有可用版本了。三条可选的恢复办法，按推荐顺序：

1. **用一个新的版本号重新出包并安装。** 全程不动那个坏目录，失败了也还能回退；
2. **回退到上一个版本**：`$HOME/.local/bin/civic-work-desk-rollback`；
3. 确认无误后**手工删除**安装程序打印出来的那个版本目录，再重新运行安装程序。
   这一步由你显式执行，安装程序不会替你做。

三种办法都不会影响浏览器里的业务数据——它不在程序目录里。

## 七、回退

`$HOME/.local/bin/civic-work-desk-rollback` 切回上一个版本并重启服务。

要知道的一件事：**回退只回退程序，不回退数据。** 本产品不支持数据库降级。如果某个版本的发布说明
写了「此版本引入数据结构迁移」，那么跨过它的回退就不安全——这种情况下正确做法是导出 JSON 备份，
而不是赌一次回退。

## 八、卸载

`civic-work-desk-uninstall`

会删除：程序文件、五个命令、菜单项、运行状态、本程序的日志。

**不会**删除：浏览器里的业务数据、360 浏览器配置、你下载的 JSON 备份、你导出的 XLSX / DOCX。

所以卸载后重装同一个地址，原来的记录还在。要彻底清除数据，得在浏览器的站点数据设置里手动删除
该来源，或者重装后用应用内的「清空全部本机数据」。卸载脚本不会替你做这件事。

## 九、出问题时

先跑：

```sh
civic-work-desk-status
```

它会分清三种看起来一样的故障：程序文件缺失、本地服务没起来、端口被别人占用。

日志（只有启动和状态信息，不含任何业务内容）：

```
~/.local/state/civic-work-desk/logs/launcher.log
~/.local/state/civic-work-desk/logs/httpd.log
```
