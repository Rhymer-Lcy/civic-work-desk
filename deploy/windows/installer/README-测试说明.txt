政务工作记录台 — Windows 试用说明（版本 0.2.0-rc.1）
==================================================

这是一个待现场验证的候选版本：Windows x64 0.2.0-rc.1，发布者 Rhymer-Lcy。

  - 主要目标：Windows 11 x64；
  - 旧系统兼容性目标：Windows 10 22H2 x64（内部版本 19045），需要在真实计算机上验证。

兼容性尚未认证，请当作试用，重要记录请自行导出备份。
本版本取代 RC3 用于新的现场验证；RC1–RC3 仍保留在发布页面，未被删除或修改。


一、怎么用（五步）
------------------

1. 下载安装包；
2. 双击安装包，按提示完成安装；
3. 从开始菜单或桌面打开“政务工作记录台”；
4. 正常使用，并定期导出 JSON 备份；
5. 如有异常，运行“收集诊断信息”，并将诊断文件（TXT）反馈给维护人员。

全程不需要输入任何命令，也不需要管理员权限。


二、支持哪些系统
----------------

  - Windows 11 x64：主要目标。
  - Windows 10 22H2 x64（内部版本 19045）：旧系统兼容性目标。

在 Windows 10 22H2 上安装时会提示：Windows 10 已于 2025 年 10 月 14 日结束支持。
本程序可以在 Windows 10 22H2 上安装和使用，但建议尽早升级到 Windows 11。
这个提示只是告知，不会阻止安装。Windows 10 结束支持后，只有加入扩展安全更新（ESU）
计划的设备还能收到安全更新；这台计算机自身的安全状况由其管理员负责，安装本程序不会改变这一点。

以下系统不在支持范围内，安装程序会说明原因并停止，不会写入任何安装文件：
Windows 7、Windows 8、Windows 8.1、22H2 以外的 Windows 10 版本、Windows Server、
32 位（x86）Windows，以及 ARM64 设备。

不确定自己的系统版本时：按 Win + R，输入 winver 回车，窗口中会显示
版本（例如 22H2）和内部版本号（例如 19045.6466）。


三、从旧版本（RC3）升级
----------------------

如果这台计算机装过旧版本 RC3，可以直接运行新的安装包升级，记录会保留：

  1. 升级前，先在“设置 → 导出 JSON 备份”导出一份备份；
  2. 关闭所有已打开的政务工作记录台页面；
  3. 运行新的安装包，它会沿用原来的安装位置（安装前的“准备安装”页会显示
     安装位置和“升级”字样）；
  4. 从开始菜单打开政务工作记录台。浏览器会先显示一个检查页面，确认浏览器
     将使用的是新版本，这一步可能需要一两分钟，请不要关闭该页面：
       - 如提示“检测到其他政务工作记录台页面仍在打开”，请先保存这些页面中
         尚未保存的内容并关闭它们，再点“重试”；
       - 出现“进入新版本”按钮后，点击即可进入；
       - 如提示“暂时无法确认”，请关闭其他政务工作记录台页面后点“重试”；
  5. 首次打开新版本时，记录会自动升级为新的数据格式，原有记录不会丢失。

升级之后请注意：

  - 请勿再安装 RC1–RC3 的安装包，也不要回退到 RC3。旧版本不认识新版本的
    上下级事项关系，在旧版本中编辑或删除事项会损坏这些关系。
    在“查看运行状态”里，可回退版本一行会注明旧版本已禁止回退，这是有意的保护。
  - 升级过程中如果有旧版本的页面一直开着，请不要在那个旧页面里编辑记录；
    关闭它，从开始菜单重新打开即可。


四、安装位置
------------

默认安装到当前用户目录：

    %LOCALAPPDATA%\CivicWorkDesk

全新安装时可以改到别的位置，例如：

    D:\Applications\CivicWorkDesk
    D:\政务工作记录台

安装位置可以带空格和中文。不能使用系统目录、Program Files、
驱动器根目录或网络位置——选中这类位置时安装程序会说明原因，
请另选一个当前用户可写的本地目录。

升级或修复时会沿用上次的安装位置，不会另外装一份。
点击“安装”之前，“准备安装”页总会显示最终的安装位置和安装类型
（全新安装、升级或修复）。


五、安装前可以先核对文件
------------------------

发布页面上与安装包同名的 .sha256 文件里，是这个安装包应有的校验值。
需要核对时，在安装包所在文件夹的地址栏输入 powershell 回车，然后执行：

    Get-FileHash .\CivicWorkDesk-Windows-x64-0.2.0-rc.1-Setup.exe

把显示的 Hash 与 .sha256 文件中的值比对，一致即可。
这一步是可选的，不做也能安装。


六、关于 Windows 安全提示
-------------------------

本候选版本未进行 Authenticode 代码签名，因此 Windows SmartScreen
可能显示来源或信誉提示。该提示本身不能证明程序安全或不安全。

请仅从项目正式 GitHub Release 获取安装包，并在需要时核对 SHA-256。
如有疑虑，请勿安装。

请勿关闭 Windows Defender 或 SmartScreen，也不要关闭“智能应用控制”或其他安全软件。
如果安全软件或系统策略阻止了程序运行，程序会弹出说明；请运行
“收集诊断信息”，把诊断文件反馈给维护人员，由维护人员判断下一步。


七、它会在这台计算机上做什么
----------------------------

会做的：

  - 把程序安装到你选择的目录（默认在当前用户目录下）；
  - 在当前用户的开始菜单创建快捷方式，并按你的选择创建桌面快捷方式；
  - 运行时在本机启动一个只监听 127.0.0.1:8765 的本地服务，
    再用你默认的浏览器打开固定访问地址 http://127.0.0.1:8765/。

不会做的：

  - 不需要管理员权限，不会弹出提权对话框
    （若出现提权对话框，说明有异常，请反馈给维护人员）；
  - 不安装 Node、Python、.NET、PowerShell 7 或任何开发环境；
  - 不写入 Program Files，不写入 HKEY_LOCAL_MACHINE；
  - 不安装 Windows 服务，不创建计划任务，不修改防火墙，不修改系统 PATH。

关于网络：安装和使用不依赖互联网。政务工作记录台不会主动向外部服务
上传业务数据。浏览器、操作系统及浏览器扩展自身的网络行为不在本程序
控制范围内。


八、数据保存在哪里
------------------

工作记录保存在浏览器中，与浏览器来源（origin）
http://127.0.0.1:8765/ 关联。更改协议、主机名或端口会改变浏览器来源；
更换浏览器或浏览器配置文件也会使用独立的站点存储。

由此有几件事需要知道：

  1. 请始终从开始菜单或桌面快捷方式打开。手动输入地址时必须是
     http://127.0.0.1:8765/ ；用 localhost 等其他地址打开，看到的是一个
     空白的程序，原有记录并没有丢失，换回固定访问地址即可看到。
  2. 不同浏览器或不同浏览器配置文件通常使用彼此独立的站点存储。
     请持续使用同一浏览器及同一浏览器配置文件。
  3. 卸载程序不等于删除数据。工作记录保存在浏览器的站点数据中，
     卸载不会删除该站点数据，也不会删除已导出的 JSON、
     Excel（.xlsx）、Word（.docx）文件。
  4. 若以后使用同一浏览器及同一浏览器配置文件，并通过同一固定访问地址
     安装兼容版本，原有记录仍可访问。

安装位置与数据无关：程序装在哪个目录不影响浏览器来源，
换目录重装不会改变记录的归属。

重要数据请使用“设置 → 导出 JSON 备份”自行留存一份。


九、如果需要换一个安装位置
--------------------------

本版本不提供“就地迁移”功能。请按以下顺序操作：

  1. 先导出一份 JSON 备份；
  2. 卸载程序；
  3. 重新安装到新位置。

固定访问地址不变，因此浏览器中的记录不受影响。


十、打不开时怎么办
------------------

打不开时程序会弹出一个说明窗口，常见的几种：

  - “端口 8765 已被其他程序占用”：本机有其他程序占用了该端口。
    程序不会强行结束无法确认归属的进程，也不会改用其他端口；
    更换端口会改变浏览器来源，原有记录不会在新的来源下显示。
    请关闭占用该端口的程序后重试。
  - 说明中提到“被 Windows 的安全策略阻止运行”“被 Windows 的应用程序控制阻止运行”
    或“安全软件阻止了本地服务程序运行”：请不要关闭安全功能，按下一条收集诊断
    信息并反馈。
  - “无法自动打开浏览器”：本地服务已经就绪，可在浏览器地址栏手动输入
    说明窗口中给出的地址 http://127.0.0.1:8765/api/civic/start ，
    它会先确认浏览器将使用的版本，再进入程序。

其他异常：开始菜单 → 政务工作记录台 → 维护工具 → 收集诊断信息。
它会在桌面生成 CivicWorkDesk-诊断信息-<日期时间>.txt，请将该文件反馈给维护人员。

诊断文件开头有一段“诊断结论”，列出查到的问题类别（系统不在支持范围、
安全策略、程序被拦截、端口冲突、浏览器无法打开、本地服务故障、访问地址
不一致）。文件中只有系统版本、程序运行限制策略是否配置、程序版本、
本地服务运行状态和程序自身的运行日志。用户目录已替换为环境变量形式；
如果你把程序装在自选目录，诊断文件只记录盘符（显示为
D:\<CUSTOM_INSTALL_ROOT>）以及该路径的特征（是否含空格、是否含非 ASCII
字符、层级与长度），不记录你所选择的目录名。文件中不含账号名、计算机名，
也不含任何工作记录或浏览器数据。

安装过程本身失败时，安装程序会在桌面生成
CivicWorkDesk-安装诊断-<日期时间>.txt，同样请一并反馈。


十一、顺便帮我们看一件事
------------------------

如果程序能正常打开，请再点一下：
开始菜单 → 政务工作记录台 → 维护工具 → 浏览器兼容性检查

页面会列出一组检查结果，点“复制全部结果”，把那段文字一并反馈。
这能说明这台计算机上的浏览器是否完整支持离线使用。

在 Windows 10 22H2 上试用时，请同时告诉我们：winver 显示的版本和内部版本号、
使用的浏览器及其版本。


十二、当前不作的承诺
--------------------

Windows 兼容性尚未认证。本版本只在一台 Windows 11 开发用计算机上按真实
安装包完整走过一遍验收，尚未在任何同事的计算机上运行过，也尚未在
Windows 10 真机上运行过。这次试用就是我们需要的现场证据。
