政务工作记录台 — Windows 11 试用说明
====================================

这是一个待现场验证的候选版本（Windows 11 x64 RC1）。
兼容性尚未认证，请当作试用，不要立刻当成唯一的记录工具。


一、怎么用（五步）
------------------

1. 双击安装包；
2. 按提示安装；
3. 从开始菜单打开“政务工作记录台”；
4. 正常使用；
5. 有异常时运行“收集诊断信息”，把生成的 txt 发回来。

不需要输入任何命令，不需要管理员权限。


二、安装前可以先核对文件
------------------------

安装包旁边有一个同名的 .sha256 文件，里面是这个安装包应有的校验值。
想核对的话，在安装包所在文件夹的地址栏输入 powershell 回车，然后执行：

    Get-FileHash .\CivicWorkDesk-Windows-x64-2026.09.24-rc1-Setup.exe

把显示的 Hash 和 .sha256 文件里的值比一下，一致即可。
（这一步是可选的，不做也能安装。）


三、可能会看到的安全提示
------------------------

这个安装包**没有代码签名证书**，所以 Windows SmartScreen 可能会提示
“Windows 已保护你的电脑”，或者浏览器下载时提示“不常见的下载”。

原因是签名证书尚未采购，不是这个程序有问题——但这一点我们如实告知，
请你自己判断是否继续。如果决定继续：点“更多信息”→“仍要运行”。

**请不要为此关闭 Windows Defender 或 SmartScreen。** 我们不会要求你降低
系统安全设置；如果你不放心，直接告诉我们，不装也完全可以。


四、它会在你的电脑上做什么
--------------------------

会做的：

  - 把程序装到你自己的用户目录：%LOCALAPPDATA%\CivicWorkDesk\
  - 在你自己的开始菜单里建几个快捷方式；
  - 运行时在本机启动一个只监听 127.0.0.1:8765 的小服务，
    然后用你默认的浏览器打开这个地址。

不会做的：

  - 不需要管理员权限，不会弹提权框（如果弹了，说明有问题，请告诉我们）；
  - 不装 Node、Python、.NET、PowerShell 7 或任何开发环境；
  - 不写 Program Files，不写 HKEY_LOCAL_MACHINE；
  - 不装 Windows 服务，不建计划任务，不改防火墙，不改系统 PATH；
  - 不联网。所有数据都在本机，程序本身不向外发送任何东西。


五、数据在哪里
--------------

你的工作记录保存在**浏览器**里，绑定在 http://127.0.0.1:8765/ 这个地址上，
不在安装目录里。这带来两件需要知道的事：

  1. **卸载程序不等于删除数据。** 卸载只删程序本身；记录、已导出的
     JSON 备份、Excel 和 Word 文件都还在。以后在同一地址重装兼容版本，
     记录会重新出现。
  2. **换浏览器等于换了一套数据。** 用 Edge 建的记录，在 Chrome 里看不到。
     请固定用同一个浏览器。

重要数据请用“设置 → 导出 JSON 备份”自己留一份。


六、如果打不开
--------------

  - 提示“端口 8765 已被其他程序占用”：说明本机有别的程序占了这个端口。
    程序不会去结束它，也不会改用别的端口（换端口等于打开一个空白的新应用）。
    请关掉占用它的程序再试。
  - 其他任何异常：开始菜单 → 政务工作记录台 → **收集诊断信息**，
    它会在桌面生成一个 txt，把那个文件发回来即可。
    那个文件里只有系统版本、程序版本、运行状态和程序自己的日志，
    没有你的任何工作记录，也没有浏览器数据，可以直接发。


七、顺便帮我们看一件事
----------------------

如果程序能正常打开，请再点一下：
开始菜单 → 政务工作记录台 → **浏览器兼容性检查**

页面上会列出一串检查结果，点“复制全部结果”，把那段文字一起发回来。
这能告诉我们你这台机器上的浏览器是否完全支持离线使用。


八、现在不承诺什么
------------------

Windows 兼容性**尚未认证**。这个版本只在一台开发机上按真实安装包完整跑过
一遍验收，没有在任何同事的机器上运行过。你这次试用就是我们要的证据。
