政务工作记录台 — Windows 11 试用说明
====================================

这是一个待现场验证的候选版本（Windows 11 x64 RC3）。
RC3 取代 RC2 用于现场验证；RC2 仍然保留在发布页面，未被删除或修改。
兼容性尚未认证，请当作试用，重要记录请自行导出备份。


一、怎么用（五步）
------------------

1. 双击安装包；
2. 按提示选择安装位置并完成安装；
3. 从开始菜单或桌面打开“政务工作记录台”；
4. 正常试用，并定期导出 JSON 备份；
5. 如有异常，运行“收集诊断信息”，并将诊断文件（TXT）反馈给维护人员。

全程不需要输入任何命令，也不需要管理员权限。


二、安装位置
------------

默认安装到当前用户目录：

    %LOCALAPPDATA%\CivicWorkDesk

安装过程中可以改到别的位置，例如：

    D:\Applications\CivicWorkDesk
    D:\政务工作记录台

安装位置可以带空格和中文。不能使用系统目录、Program Files、
驱动器根目录或网络位置——选中这类位置时安装程序会说明原因，
请另选一个当前用户可写的本地目录。

升级或修复时会沿用上次的安装位置，不会另外装一份。


三、安装前可以先核对文件
------------------------

安装包旁边有一个同名的 .sha256 文件，里面是这个安装包应有的校验值。
需要核对时，在安装包所在文件夹的地址栏输入 powershell 回车，然后执行：

    Get-FileHash .\CivicWorkDesk-Windows-x64-2026.09.24-rc3-Setup.exe

把显示的 Hash 与 .sha256 文件中的值比对，一致即可。
这一步是可选的，不做也能安装。


四、关于 Windows 安全提示
-------------------------

当前 RC 候选版本未进行 Authenticode 代码签名，因此 Windows SmartScreen
可能显示来源或信誉提示。该提示本身不能证明程序安全或不安全。

请仅从项目正式 GitHub Release 获取安装包，并在需要时核对 SHA-256。
如有疑虑，请勿安装。

请勿关闭 Windows Defender 或 SmartScreen。


五、它会在这台计算机上做什么
----------------------------

会做的：

  - 把程序安装到你选择的目录（默认在当前用户目录下）；
  - 在当前用户的开始菜单创建快捷方式，并按你的选择创建桌面快捷方式；
  - 运行时在本机启动一个只监听 127.0.0.1:8765 的本地服务，
    再用你默认的浏览器打开固定访问地址 http://127.0.0.1:8765/。

不会做的：

  - 不需要管理员权限，不会弹出提权对话框
    （若出现提权对话框，说明有异常，请反馈给维护人员）；
  - 不安装 Node、Python、.NET、PowerShell 7 或任何开发环境；
  - 不写入 Program Files，不写入 HKEY_LOCAL_MACHINE；
  - 不安装 Windows 服务，不创建计划任务，不修改防火墙，不修改系统 PATH。

关于网络：安装和使用不依赖互联网。CivicWorkDesk 不会主动向外部服务
上传业务数据。浏览器、操作系统及浏览器扩展自身的网络行为不在本程序
控制范围内。


六、数据保存在哪里
------------------

工作记录保存在浏览器中，与浏览器来源（origin）
http://127.0.0.1:8765/ 关联。更改协议、主机名或端口会改变浏览器来源；
更换浏览器或浏览器配置文件也会使用独立的站点存储。

由此有三件事需要知道：

  1. 不同浏览器或不同浏览器配置文件通常使用彼此独立的站点存储。
     请持续使用同一浏览器及同一浏览器配置文件。
  2. 卸载程序不等于删除数据。工作记录保存在浏览器的站点数据中，
     卸载不会删除该站点数据，也不会删除已导出的 JSON、
     Excel（.xlsx）、Word（.docx）文件。
  3. 若以后使用同一浏览器及同一浏览器配置文件，并通过同一固定访问地址
     安装兼容版本，原有记录仍可访问。

安装位置与数据无关：程序装在哪个目录不影响浏览器来源，
换目录重装不会改变记录的归属。

重要数据请使用“设置 → 导出 JSON 备份”自行留存一份。


七、如果需要换一个安装位置
--------------------------

本版本不提供“就地迁移”功能。请按以下顺序操作：

  1. 先导出一份 JSON 备份；
  2. 卸载程序；
  3. 重新安装到新位置。

固定访问地址不变，因此浏览器中的记录不受影响。


八、打不开时怎么办
------------------

  - 提示“端口 8765 已被其他程序占用”：说明本机有其他程序占用了该端口。
    程序不会强行结束无法确认归属的进程，也不会改用其他端口；
    更换端口会改变浏览器来源，原有记录不会在新的来源下显示。
    请关闭占用该端口的程序后重试。

  - 其他异常：开始菜单 → 政务工作记录台 → 维护工具 → 收集诊断信息。
    它会在桌面生成一个诊断文件（TXT），请将该文件反馈给维护人员。

    诊断文件中只有系统版本、程序版本、本地服务运行状态和程序自身的
    运行日志。用户目录已替换为环境变量形式；如果你把程序装在自选目录，
    诊断文件只记录盘符（显示为 D:\<CUSTOM_INSTALL_ROOT>）以及该路径的
    特征（是否含空格、是否含非 ASCII 字符、层级与长度），不记录你所选择
    的目录名。文件中不含账号名、计算机名，也不含任何工作记录或浏览器数据。

  - 安装过程本身失败时，安装程序会在桌面生成
    CivicWorkDesk-安装诊断-<日期时间>.txt，同样请一并反馈。


九、顺便帮我们看一件事
----------------------

如果程序能正常打开，请再点一下：
开始菜单 → 政务工作记录台 → 维护工具 → 浏览器兼容性检查

页面会列出一组检查结果，点“复制全部结果”，把那段文字一并反馈。
这能说明这台计算机上的浏览器是否完整支持离线使用。


十、当前不作的承诺
------------------

Windows 兼容性尚未认证。本版本仅在一台开发用计算机上按真实安装包
完整走过一遍验收，尚未在任何同事的计算机上运行过。
这次试用就是我们需要的现场证据。
