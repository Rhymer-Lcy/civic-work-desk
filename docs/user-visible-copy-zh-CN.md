规范依据见 [copy-style-zh-CN.md](copy-style-zh-CN.md)；自动校验见 `npm run audit:copy`。

不包含应用内部产品界面文案（`src/`），那属于产品 UX。
不包含冻结发布包内的历史文案与既往验收记录——历史材料保持原样。

状态列：**RC2** 为本次修订；**沿用** 为未改动且符合规范；**待维护** 为已知不符、排入 UOS 下次维护发布
