## Documented intended behaviour

Uninstall does **not** clear browser-resident CivicWorkDesk site data. The records live in the browser's
IndexedDB for the origin `http://127.0.0.1:8765/`, and the uninstaller says so explicitly rather than
removing them: deleting program files costs a reinstall, deleting site data costs the records
irreversibly, and a script cannot know whether the operator holds a current backup.

Consequence, by design: reinstalling at the same origin brings the previous records back. That is not
residue.
